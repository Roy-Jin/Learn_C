# Learn_C - C语言学习项目

这是一个用于学习和练习C语言的代码仓库，包含从基础到进阶的多个示例代码文件。

## 项目内容

- 学习和分享大家的C语言代码
- 用于存放大家的C语言代码文件
- 用于分享大家的C语言编程经验

## 欢迎加入学习

欢迎所有对C语言感兴趣的学习者使用本仓库！这里收集了精心整理的示例代码，可以帮助你从零开始学习C语言编程。

## 如何使用

1. 成为项目的协作者，提交你的代码文件
2. 在`Users\`内添加你的用户名，内部用户存储你的C语言代码文件
3. 在`Temp\`内添加公共的临时文件，用于存放你正在学习的中间文件
4. 在`Public\`内添加公共代码文件，供大家学习参考

Happy Coding!
